功能Features

捕获一次，永久可查。Capture it once, find it forever.

每一次捕获都进入同一个可搜索的本地资料库。无账号，无云端，无遥测。Every capture lands in one searchable, local history. No accounts, no cloud, no telemetry.

想怎么截就怎么截Capture any way you need

顶部模式胶囊一键切换：截图、滚动截图、录屏、文字识别。区域截图带像素网格放大镜——坐标与颜色实时跟随，Shift 在 HEX/RGB 间切换，⌘C 复制色值。支持全屏、单击选中窗口与延时截图。滚动截图：选区中央点 ▶ 开始，手动、自动或把鼠标移到选区边缘滚动，再选停止、保存图片或 ✓ 复制。A draggable mode capsule switches between capture, scrolling capture, recording and OCR. The region overlay's pixel-grid magnifier tracks coordinates and color live — Shift toggles HEX/RGB, ⌘C copies the value. Fullscreen, single-click window and delay capture. Scrolling capture: press ▶ in the selection to start, scroll manually, automatically or by moving the mouse to the selection's edge, then stop, save or ✓ copy.

安装Install

四步，大约一分钟。Four steps, about a minute.

CaptureKit 以 DMG 形式通过 GitHub Releases 分发——无需 App Store，无需安装器。CaptureKit is distributed as a DMG from GitHub Releases — no App Store, no installer.

下载 DMGDownload the DMG

始终从 GitHub Releases 页面获取最新版——本页顶部的下载按钮也始终指向那里。Always grab the latest from the GitHub Releases page — the button at the top of this page always points there too.

把 CaptureKit 拖进应用程序Drag CaptureKit into Applications

打开 DMG，把应用拖到 Applications 快捷方式上，然后推出 DMG。Open the DMG and drag the app onto the Applications shortcut, then eject the DMG.

如果 macOS 拦截首次启动If macOS blocks the first launch

CaptureKit 暂未做 Apple 公证，首次打开可能被 Gatekeeper 隔离。拖入 /Applications 后，在终端运行以下命令清除隔离属性：CaptureKit is not notarized, so Gatekeeper may quarantine it on first open. After dragging it into /Applications, run this in Terminal to clear the quarantine flag:

xattr -dr com.apple.quarantine /Applications/CaptureKit.app

只对信任来源使用——请确认软件来自 CaptureKit 官方发布页。Only do this for software you trust and downloaded from the official CaptureKit releases.

启动并授权屏幕录制Launch and grant Screen Recording

首次截图会触发系统的「屏幕录制」权限弹窗——允许后重新触发截图即可。这也是截图所需的唯一权限。The first capture triggers macOS's screen-recording permission prompt — allow it, then trigger the capture again. That's the only permission screenshots need.

清除隔离安全吗？Is removing quarantine safe?

xattr 命令只清除 macOS 给下载文件添加的标记，不会验证或改动应用本身。判断来源、再作决定——这正是公证本会替你做的事。The xattr command only clears the flag macOS adds to downloaded files; it doesn't verify or change the app. Judge the source, then decide — that's exactly what notarization would otherwise do for you.

更新如何工作How updates work

CaptureKit 通过 Sparkle 每天检查一次 GitHub Releases。更新包经 EdDSA 签名，确认后才会安装。也可随时手动检查：菜单栏右键 → 检查更新…。更新后若再次被隔离，重跑同一条 xattr 命令即可。CaptureKit checks GitHub Releases once a day through the Sparkle framework. Update packages are signed (EdDSA) and installed only after you confirm. Manual check any time: menu-bar right-click → Check for Updates…. After an update, if macOS re-quarantines the app, run the same xattr command again.

为什么每次启动都要授权屏幕录制？Why does macOS ask for screen recording again?

两种情况：① 应用正从临时位置运行（常见于直接从 DMG 打开）——按上方安装步骤把应用放入「应用程序」文件夹即可；② 从 v0.1.2 或更早版本升级到 v0.1.4 及以后时需要重新授权一次，因为应用改用了固定的签名证书。此后的更新不应再要求重新授权；如果仍然出现，请到 GitHub 提 issue。Two cases: ① the app is running from a temporary location (common when opened directly from the DMG) — finish the install steps above and launch from Applications; ② upgrading from v0.1.2 or earlier to v0.1.4 or later needs one re-grant, because the app switched to a fixed signing certificate. Later updates should not ask again; if they do, please open an issue on GitHub.

你的数据在哪里Where your data lives

  • 剪贴板历史默认关闭；删除历史会同时删除关联文件Clipboard history is off by default; deleting history deletes the files with it
  • OCR 由 Vision 框架在本机完成——任何内容都不会上传OCR runs locally via the Vision framework — nothing is uploaded anywhere
