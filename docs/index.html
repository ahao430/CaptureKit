Features

Capture it once, find it forever.

Every capture lands in one searchable, local history. No accounts, no cloud, no telemetry.

Capture any way you need

Region with magnifier and window snapping, fullscreen, or pick a window by click. Delayed captures for menus, and scrolling capture stitches a whole page into one long image — auto-scroll or manual.

region · fullscreen · window · delay 1–10 s · scrolling

Annotate before you share

Arrow, text, mosaic, blur, numbering and more. Non-destructive crop, full undo/redo. What you see is exactly what exports.

8 annotation types · crop · ⌘Z / ⌘⇧Z

Record video & GIF

Region, fullscreen or window. The control HUD never appears in the frame. Pause and resume — dead time is removed automatically.

H.264 mp4 · streaming GIF · optional system audio & mic

Trim, speed, ship

After recording: trim with a dual-handle timeline, adjust speed 0.5–2×, remove GIF frames, then export mp4 or GIF.

480p–1080p mp4 · 10–20 fps GIF · frame deletion

Search inside images

On-device OCR indexes text in every screenshot, so history search finds words inside the picture.

Vision framework · zh-Hans + English · fully offline

One history

Screenshots, recordings and clipboard items in a single local library — categories, pinning, thumbnails, auto-clean.

SQLite index · list & grid · Finder reveal

Clipboard, opt-in

Clipboard history is off until you turn it on. Sensitive-content filtering and per-app exclusion come standard; quit can wipe everything.

off by default · sensitive filter · clear on quit
Install

Four steps, about a minute.

CaptureKit is distributed as a DMG from GitHub Releases — no App Store, no installer.

Download the DMG

Always grab the latest from the GitHub Releases page — the button at the top of this page always points there too.

Drag CaptureKit into Applications

Open the DMG and drag the app onto the Applications shortcut, then eject the DMG.

If macOS blocks the first launch

CaptureKit is not notarized, so Gatekeeper may quarantine it on first open. After dragging it into /Applications, run this in Terminal to clear the quarantine flag:

xattr -dr com.apple.quarantine /Applications/CaptureKit.app

Only do this for software you trust and downloaded from the official CaptureKit releases.

Launch and grant Screen Recording

The first capture triggers macOS's screen-recording permission prompt — allow it, then trigger the capture again. That's the only permission screenshots need.

Good to know

First-launch notes.

Is removing quarantine safe?

The xattr command only clears the flag macOS adds to downloaded files; it doesn't verify or change the app. Judge the source, then decide — that's exactly what notarization would otherwise do for you.

How updates work

CaptureKit checks GitHub Releases once a day through the Sparkle framework. Update packages are signed (EdDSA) and installed only after you confirm. Manual check any time: menu-bar right-click → Check for Updates…. After an update, if macOS re-quarantines the app, run the same xattr command again.

Where your data lives

  • All captures, the history database and settings stay in ~/Library/Application Support/CaptureKit/
  • Clipboard history is off by default; deleting history deletes the files with it
  • OCR runs locally via the Vision framework — nothing is uploaded anywhere
Local-first by design

Everything stays on your Mac.

No accounts. No cloud. No telemetry. Just a fast, native tool that gets out of the way.
